# 🚀 NextJr | SouJunior Apoia.se

Landing page desenvolvida pela equipe **NextJr** durante o Hackathon SouJunior, com o objetivo de apresentar o impacto da comunidade SouJunior e incentivar o apoio ao projeto por meio da campanha no Apoia.se.

## 🎯 Sobre o projeto

A proposta consiste no desenvolvimento de uma landing page responsiva, acessível e intuitiva, apresentando a importância da SouJunior para a comunidade, seus impactos e as diferentes formas de contribuir com a iniciativa.

A aplicação direciona os usuários interessados em contribuir para a campanha oficial da SouJunior no Apoia.se.

## 🚀 Como executar

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório:

```bash
git clone <URL-DO-REPOSITORIO>
```

Entre na pasta do projeto:

```bash
cd nextjr-soujunior-apoiase
```

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

A aplicação ficará disponível no endereço informado pelo Vite no terminal.

## 🌿 Fluxo de desenvolvimento

O projeto utiliza o seguinte fluxo de branches:

```text
feature/* → develop → main
```

- `main`: versão estável do projeto.
- `develop`: integração das funcionalidades em desenvolvimento.
- `feature/*`: desenvolvimento de funcionalidades individuais.

As alterações são integradas através de Pull Requests e passam por Code Review antes do merge.

## 📝 Padrão de commits

Utilizamos Conventional Commits:

```text
feat: nova funcionalidade
fix: correção
docs: documentação
test: testes
refactor: refatoração
chore: configuração ou manutenção
```
